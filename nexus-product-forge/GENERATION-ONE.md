# Generation One autonomy boundary

## What NEXUS does without user setup

- interprets one plain-language intent;
- chooses one of four builders;
- emits strict LUMEN/1;
- compiles a runnable browser project;
- writes source, metadata, tests, and documentation;
- blocks malformed or incomplete builds;
- previews the generated project in a sandbox;
- hashes every file with SHA-256;
- packages all files for download;
- runs compiler and mobile-browser verification in GitHub Actions.

## What is not claimed yet

- general-purpose autonomous software engineering;
- physical iPhone verification;
- independent release certification;
- automatic repository creation or deployment;
- arbitrary npm, Python, Rust, C++, or WebAssembly compilation;
- research-paper understanding;
- large language model inference;
- self-modifying engines.

Those capabilities belong to later generations and remain quarantined until working code and evidence exist.

## Next engine layers

1. Toolsmith Core — reusable project graph, file writer, validators, evidence ledger.
2. LUMEN language — modules, typed resources, systems, tests, permissions, target profiles.
3. Engine Foundry — simulation, game, AI, UI, data, networking, audio, and physics engines.
4. Open Library Registry — pinned source, license, capability, platform, tests, and known limits.
5. Research Forge — papers to reproducible experiments with citations and explicit uncertainty.
6. Agent Workshop — builder/tester/verifier separation and repair loops.
7. Native Worker Bridge — optional ASUS ROG Ally X execution for GPU, Windows, controller, and packaged builds.
